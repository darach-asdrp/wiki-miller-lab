
## Making antibiotic stocks

Generally, either Darach has already made it or you should be doing this 
with Darach. Making stocks is important, but these are concentrated stocks
that go far, and so preparing them uses a costly amount of consumable reagents.
So... talk to Darach when doing this!

Typically we are going to:

- Learn more about the antibiotic, particularly what concentrations it's used
    in, what to dissolve it in, and if and how we need to sterilize it
- Weigh and dissolve it
- Usually filter sterilize but sometimes not (DMSO, etOH)

## Antibiotics for yeast

- G418
- CloNat
- Hygromycin
- 5-FU

## Antibiotics for bacteria

- Chloramphenicol
- Ampicillin and Carbenicillin
- Kanamycin
- Streptomycin
- Zeocin
- Tetracycline
